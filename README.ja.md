# jev-jam

[English](README.md) | 日本語

五線譜を叩いて伴奏すると、AIのサックスがその場でアドリブソロを返してくる。ブラウザだけで遊べるジャムセッションです。

ソロのフレーズを決めているのは、TypeSafe AI の判断特化モデル [Jev](https://docs.typesafe.ai) です。楽譜を丸ごと生成させるのではなく、「次の半小節はどんなリズムで、音はどちらへ動くか」という小さな選択を1小節に何度も判断させ、その結果を演奏に組み立てています。楽器が弾けなくても、画面を叩くだけでバンドと合わせられます。

## 遊び方

1. 五線譜を叩くと、バンドが演奏を始める
2. 叩いた高さの音をいちばん上にした和音が鳴る。押しているあいだは音が伸びる
3. 伴奏に合わせて、Jevのソロが金色の光の線になって流れていく

高いところを叩くほど演奏は盛り上がり、ソロもそれに応えて激しくなります。短く刻めば鋭く、長く伸ばせばしっとりと吹きます。

画面下の「裏側を見る」を開くと、Jevが小節ごとに何を選んだか、次のソロの準備に何ミリ秒かかったかが見えます。テンポや楽器の変更、Jevと2小節ずつ交代で弾く掛け合いもここで設定できます。

キーボードだけでも操作できます。スペースで叩き、上下キーで叩く高さを変え、数字キーでコードを弾きます。

## 仕組み — 書かせずに、選ばせる

言語モデルに「このコードに合うソロを書いて」と頼むと、返ってくるまでに時間がかかり、出てくる音も安定しません。演奏はテンポ120なら1小節2秒で進むので、その待ち時間は許されません。

そこで役割を分けました。音楽理論で決まる部分、つまりコードとキーから使える音を絞る作業はルールが受け持ちます。Jevが受け持つのは、絞った候補のどれを選ぶかの判断だけです。候補にはそれぞれ「ガイドトーン。コードの色を決める音」「3度とぶつかるので、短い経過音としてだけ使う」といった説明文を添えて渡します。

Jevは一つの答えだけでなく、選択肢ごとの確率を返します。**この確率から毎回抽選する**ので、同じコード進行でも、弾くたびに違うソロになります。最上位の選択肢の確率は平均で40〜60%ほどで、毎回同じフレーズに決め打ちされることはなく、それでいて音楽として外れない程度に散らばります。

開発中に測った値では、1小節ぶんの判断を1回のリクエストにまとめて送ると、応答は中央値174ms・最大263msでした（日本から計測）。1小節の2秒に十分収まるので、次にユーザーが弾きそうなコードすべての分のソロを、選ばれる前に用意しておけます。どのコードを弾いても、待たずにソロが付いてきます。

ほかにも、次のような判断をJevに任せています。

- 8小節ごとに、いまのコード進行を続けるか別の進行へ移るか
- 掛け合いで、ユーザーのフレーズを真似るか、返すか、畳みかけるか、落ち着かせるか
- ユーザーの伴奏が「しっとり」か「激しい」かを踏まえた、ソロの強弱

伴奏、ドラム、音の鳴らし方はすべてルールで動かしており、Jevは使っていません。Jevを呼ばずにルールだけで確率を作るモードもあり、設定から切り替えられます。

設計の判断は [docs/adr](docs/adr/README.md) に55本の記録として残しています（日本語）。採用しなかった案や、うまくいかなかったことも含めています。

## 動かし方

Node.js 22.18 以上と pnpm が必要です。

```sh
pnpm install
cp .env.example .env   # TYPESAFE_API_KEY を書き込む
pnpm dev
```

http://localhost:3000 を開きます。`TYPESAFE_API_KEY` を設定しなければ、Jevの代わりにでたらめな確率を返すダミーで動きます。キーがあっても、`http://localhost:3000/?mock=1` で開けばダミーになります。Jevの呼び出しは従量課金なので、画面の確認はこちらがおすすめです。

| 環境変数 | 用途 |
| --- | --- |
| `TYPESAFE_API_KEY` | Jev の APIキー。[console.typesafe.ai](https://console.typesafe.ai/keys) で発行する |
| `BASIC_AUTH_USER` / `BASIC_AUTH_PASSWORD` | 公開するときのBasic認証。両方設定したときだけ有効になる |

テストは `pnpm test`、型チェックは `pnpm typecheck` で実行します。

## 技術構成

- Next.js 16（App Router）と TypeScript
- 発音は Tone.js。ソロの音には、しゃくりやビブラートを付けるために自前の再生処理を使う
- Jev は Next.js の API ルートからだけ呼び、APIキーはブラウザに渡さない
- Vitest によるテスト
