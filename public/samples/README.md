# 音源の出典とライセンス

このディレクトリの音源は外部で公開されているものを取得した（2026-10-13。トランペットとトロンボーンは 2026-10-14）。
容量を抑えるため、短3度おきの音だけを置いている。間の音は再生時に近い音から作る。

| ディレクトリ | 内容 | 出典 | ライセンス |
| --- | --- | --- | --- |
| `sax-recorded/` | サックス（楽器の録音） | [nbrosowsky/tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) の `samples/saxophone` | CC BY 3.0 |
| `trumpet/` | トランペット（楽器の録音） | [nbrosowsky/tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) の `samples/trumpet` | CC BY 3.0 |
| `trombone/` | トロンボーン（楽器の録音） | 同 `samples/trombone`（ソロで使う C3〜F4 だけを置いている） | CC BY 3.0 |
| `tenor-sax/` | テナーサックス | [gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts) の FluidR3_GM `tenor_sax` | CC BY 3.0 |
| `electric-piano/` | エレクトリックピアノ | 同 FluidR3_GM `electric_piano_1` | CC BY 3.0 |
| `bass/` | ウッドベース | 同 FluidR3_GM `acoustic_bass` | CC BY 3.0 |

- FluidR3_GM は Frank Wen によるサウンドフォント。
- CC BY 3.0: https://creativecommons.org/licenses/by/3.0/
- `sax-recorded/` はサックスの種類（アルトかテナーか）が配布元に書かれていない。収録音域は C#3〜A5。

公開する場合は、アプリ内かこのファイルへのリンクで上記のクレジットを表示すること。
