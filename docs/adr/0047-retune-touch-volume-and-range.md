# 0047. しっとりの音量は下げず、激しいときは大きく、高すぎない音域にする

- 日付: 2026-10-14
- ステータス: Accepted（0046 の音量と音域の値を置き換える）
- 種別: 設計判断

## 背景

0046 を聴いたユーザーの評価。

- しっとりした部分の音量は下げなくていい。今だとほとんど聞こえなくなる
- 激しいところの音量はもうちょっと上げて
- 激しいところは上限が高すぎる。不自然な音色に聞こえるので、そこまで高くしなくていい

録音を再生速度で高く引き伸ばすほど、音色が不自然になる（録音の最高音より上は特に）。

## 決定

- 音の大きさの倍率: しっとり 0.7 → 1（下げない）、激しい 1.3 → 1.5、ほどほどに刻む 1.12 → 1.15
- 大きくする倍率のときは、音の強さの上限（1）を超えてよいことにした。上限で頭打ちになると、倍率を上げても大きく聞こえなかったため
- 激しいときの音域: 上限を「いちばん上」から「音域の88%の位置」に下げ（サックスなら G5 → D5）、下限は45%の位置まで引き上げる（ただし1オクターブは残す）
- 激しいときに目指す高さ: 音域の88% → 70%

途中で一度、上限を下げると同時に下限の引き上げも弱めたら（25%）、激しいときの平均の高さが「ふつう」と同じ（67.0）になり、高い音域で動く感じが消えた。下限をしっかり引き上げる形に直した。

## 結果

ダミー（`?mock=1`、確率はでたらめ）で測った。

8小節つないだときの、5〜8小節目の平均の高さ（MIDIノート番号）:

| 伴奏 | 0046 | 0047 |
| --- | --- | --- |
| しっとり | 62.9 | 63.8 |
| ふつう | 68.2 | 66.0 |
| 激しい | 73.2（C#5 付近） | 71.7（B4 付近） |

1小節あたりの音の強さ: しっとり 約0.57、ふつう 約0.51、激しい 約1.08（0046 では 0.31 / 0.50 / 0.77）。

- 音色と音量の聴こえ方は、ユーザーの耳で確認してもらう
