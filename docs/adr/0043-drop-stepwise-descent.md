# 0043. 順次下降を一覧から外す

- 日付: 2026-10-14
- ステータス: Accepted
- 種別: 設計判断

## 背景

0042 で繰り返し型にした「順次下降」（`Fmaj7 | Em7 | Dm7 | Cmaj7 |`）について、ユーザーから「下降のコード進行は伴奏を取りづらいから、外していいかも」と言われた。

## 決定

順次下降を定番進行の一覧から外した。移り先にも、毎小節の候補にも出ない。

「サブドミナントマイナーからの下降」（`Fmaj7 Fm7 Em7 A7`）は、移り先ではなく、ふだん自動で乗ることもほぼないので残した。

## 結果

移り先の選択肢は10個から9個になった。テストと型チェックは通った。
