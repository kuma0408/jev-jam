# 0051. Jevのモデルを jev-1.14.0 に固定する

- 日付: 2026-10-16
- ステータス: Accepted
- 種別: 技術選定

## 背景

これまでは `model: "jev-latest"` を送っていた。公式ドキュメント（Models）によると、2026-10-16時点で `jev-latest` が指すのは `jev-1.13.0` で、最新リリースの `jev-1.14.0`（2026-10-14公開）ではない。
エイリアスは新版が出ると黙って切り替わるので、勉強会の当日に応答の傾向が変わるおそれがある。

## 検討した選択肢

- 案A: `jev-latest` のまま / 何もしなくてよい / 指す先がいつ変わるか分からない。現状は1.13のまま
- 案B: `jev-preview` / 1.14を指す / プレビュー版が出ると先にそちらへ移るので、同じく固定にならない
- 案C: `jev-1.14.0` を直接指定する / 版が固定され、最新リリースも使える / 次の版に移るときはコードを直す必要がある

## 決定

案Cを採用した。公式も、閾値を特定の版に合わせて調整している場合は固定IDを送るよう勧めている。
`createJevClient` の既定値を `jev-1.14.0` にした。

## 結果

- 送る `model` が `jev-1.14.0` になることを、fetchを差し替えたテストで確かめた（本物のJevは呼んでいない）
- これまでの実測や調整（強さの確率、音域など）は1.13を前提にしている。1.14で確率の傾向が変わる可能性があり、まだ確かめていない
- 固定IDは `GET /v1/models` の一覧には出ないが、`model` フィールドでは受け付けると公式に書かれている

## 勉強会メモ

- 「latest」は最新ではなかった。エイリアスの指す先は、ドキュメントで確かめるまで分からない
