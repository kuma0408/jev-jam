# 0054. Jevを呼ばずにルールで確率を作るモードを足し、裏側の設定で切り替えられるようにする

- 日付: 2026-10-16
- ステータス: Accepted
- 種別: 設計判断

## 背景

ユーザーから「裏側の設定に、完全ルールベースのモードを設けて、Jevは呼び出さずに、ランダムに選ばれた確率か、ルールベースで導いてほしい方向（激しいタップ回数なら音量も大きく、少なければしっとりしたフレーズに）にできないか」と頼まれた。

発表の質疑で「ルールベースで作っても同じでは？」と聞かれる想定があり、資料には「Jevとダミーを同じ条件で聴き比べたことはまだ無い」と書いていた。聴き比べられるモードがあれば、その場で音で答えられる。

Jevの呼び出しは `DecisionClient` という1つの口にまとめてあり、開発用のダミー（でたらめな確率）と差し替えられる。確率を受け取った後のルールの補正（盛り上がりに合う音数へ寄せる、しっとりなら16分音符を減らす、音量の倍率など）は、どの差し替え先でも効く。

## 検討した選択肢

確率の作り方（ユーザーの選択）:

- ルールで確率を作る（採用）
- Jev・ルール・ランダムの3つから選べる: 比較は細かくできるが、設定の選択肢が増える
- ランダムの確率（いまのダミー）を選べるようにするだけ: 強さなど、Jevに任せている部分がでたらめになる

公開版で使えるか（ユーザーの選択）:

- 使えるようにする（採用）: ルールのモードはJevを呼ばないので課金が無い。発表当日、公開版で切り替えて見せられる
- 開発中だけ: 開発用のダミーと同じく、本番では無効

## 決定

- `DecisionClient` と同じ形の、ルールの判断役（`createRuleClient`）を足した。状況の文は読まず、アプリの値（盛り上がり、4小節の中の位置、進行を続けた小節数）から確率を作る
  - 強さ: 盛り上がり（押し方から決まる）で soft / medium / loud に寄せる。激しいと loud 70%、しっとりだと soft 60%
  - 強弱の動き: 盛り上がっていればだんだん強く、静かならだんだん弱くに寄せる
  - 前のフレーズとの関係: 4小節の最後の小節では「間で応える」に60%
  - 進行: 始めて8小節未満なら「続ける」に80%
  - それ以外（リズム、音の動き、4小節の形、高さの流れ など）は均等。あとはこれまでのルールの補正に任せる
- APIの依頼に `decider`（`jev` / `rules`、省略時は jev）を足した。`rules` は本番でも受け付け、開発用の `mock` より優先する
- 「裏側を見る」の設定に「判断する人」を足した。切り替えは次の依頼から効く。接続先の表示は「ルール」になる

## 結果

- テスト562件、型チェックが通った
- ダミーのまま設定で「ルール」を選んで再生し、接続先が「ルール」になり、エラーが出ないことを確かめた
- 聴き比べの結果（Jevとルールで違いが聞き取れるか）はまだ無い。ユーザーの確認待ち

## 勉強会メモ

- 判断役を1つの口にまとめていたので、「判断する人を取り替える」が数十行で済んだ
- ルールの判断役が使う規則は、Jevに渡している文の要点そのもの。違いが出るとしたら、Jevが直前4小節の流れまで読んで選び分けるところ
