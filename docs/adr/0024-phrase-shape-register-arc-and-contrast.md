# 0024. 4小節ごとに「吹く場所」と「高さの流れ」を決め、跳躍と強弱の幅を広げる

- 日付: 2026-10-13
- ステータス: Accepted（0014・0019を補う）
- 種別: 検証結果

## 背景

ユーザーの評価は「まだやっぱりワンパターン。どうすればワンパターンじゃなくなるのか」だった。
あわせて、テンポは60〜90BPMが音楽としていちばん成り立つ、という評価があった。

0014でリズムと動きを分けて組み合わせを増やし、0019で前のフレーズとの関係を持たせた後である。
選択肢を増やしても解消していないので、何が偏っているのかを数えた。

## 調べたこと

80BPMで64小節ずつ走らせた（各1回）。

リズムと動きの組み合わせは、64小節で91〜99通り使われていた。**選択肢の少なさは原因ではなかった。**
偏っていたのは、もっと表面的なところだった。

| 観点 | 結果 |
| --- | --- |
| 隣り合う音の間隔 | 59〜66%が1〜2半音。5半音以上の跳躍は9% |
| 音の高さ | 半分の音が真ん中の10半音に収まる。4小節ごとの平均は上下するだけで、向かう先が無い |
| フレーズの出だし | 53〜65%がルートか5thから |
| 強弱 | 「ゆったり」で91%が medium、「のってきた」で72%が loud |
| フレーズの長さ | すべて半小節の箱に収まる。小節まるごと休む回は0 |

違う型を選んではいるが、どれも同じ音域を、同じ歩幅で、同じ強さで、同じ長さだけ動いていた。
型の名前が違っても、耳には同じ質感に聞こえる。

## 決定

5つの案のうち、ユーザーが3つを選んだ（主題を持たせる案は見送り）。

### フレーズの長さを不揃いにする

4小節のまとまりの最初の小節で、「どこを吹いて、どこを休むか」の形をJevに選ばせる。
形は半小節8つぶんの「吹く・休む」で、10種類ある（長い一息、待ってから応える、呼びかけと間、だんだん詰める、など）。

- 形が「休む」とした場所は、Jevが何を選んでも休む
- 形が「吹く」とした場所は、Jevが休みを選んでも休まない
- 盛り上がりに合った密度の形を選ばれやすくする

### 高さの流れ

同じく最初の小節で、4小節の高さの流れをJevに選ばせる（登る、降りる、山、谷、低く、高く、中ほど）。
流れは小節ごとの高さの目標を持ち、フレーズをその高さへ寄せて鳴らす。

### 跳躍と出だし

- 跳躍のある動きを5つ足した（4度の積み重ね、6度の跳躍、7thや9thから大きく落ちる動きなど）
- 跳躍の動きを1.6倍、隣の音へ動くだけの動きを0.6倍、ルートや5thから始まる動きを0.7倍にする

### 強弱の幅

- 弱い指定と強い指定の差を広げた（0.48〜0.86 を 0.4〜0.9 に）
- 小節内の強さの動きを2つ足した（前半は強く後半は急に弱く、真ん中で盛り上がって引く）
- 盛り上がりによる寄せ方を弱め、直前の小節と同じ強さ・同じ動きを選ばれにくくした

## 結果

同じ条件で数え直した（80BPM、各64小節、1回）。

| 観点 | 前 | 後 |
| --- | --- | --- |
| 1〜2半音の動き | 59〜66% | 41〜49% |
| 3〜4半音の動き | 20〜27% | 31〜43% |
| 5半音以上の跳躍 | 9% | 15〜18% |
| ルートか5thからの出だし | 53〜65% | 29〜47% |
| いちばん多い強弱の割合 | 91%（medium）、72%（loud） | 57%（medium）、56%（loud） |
| 音の無い小節 | 0% | 11〜25% |
| 1小節の音数 | 3〜6個に63〜64%が集中 | 0個から10個以上まで散らばる |

形は選ばれたとおりに音に表れた。高さの流れは、たとえば「降りる」で小節の平均が 74→68→64→56、
「谷」で 66→61→57、「登る」で 65→67→75 と動いた。応答は中央400ms前後で変わらない。

### 途中で直したこと

- 高さの流れが最初は効かなかった。フレーズの「最初の音」を目標の高さに合わせていたので、
  上がるフレーズは目標より高く、下がるフレーズは低く偏った。フレーズ全体の真ん中を合わせるように直した
- 形が2種類の交互になった。直前の1つだけを選ばれにくくしていたため。過去3つを覚えるようにした
- 「次が休みの場所の直前では、次へつなぐ形で終わらせない」という縛りを入れかけて、外した。
  テストで、8分音符4つのような普通のフレーズまで締め出すと分かった。短い音で終わって休みに入るのは自然な終わり方である
- 形が「休む」とした場所は、0021の着地のルール（つなぐ音の後は頭から鳴らす）より優先する

### できていないこと・分からないこと

- 聴いてワンパターンが解消したかは、ユーザーの確認待ち。数字が動いたことと、良く聞こえることは別である
- 「ゆったり」では小節の4分の1が無音になる。間が多すぎる可能性がある
- 高さの流れは効かない回もある（「登る」で 67→66→70→64 など）。動きそのものが高さを決める力に負ける
- 音域は53〜77のまま。流れの目標どうしの差は最大で18半音ほどしか無い
- 主題を持たせる案は入れていない

## 勉強会メモ

- 「選択肢を増やせば多様になる」は外れた。組み合わせは十分にばらけていたのに、耳には同じに聞こえていた。
  原因を当てるには、選択肢の数ではなく、出てきた音の統計（間隔、高さ、強さ、長さ）を数える必要があった
- 小節ごとの判断を積み重ねても、長い単位の形は生まれない。4小節単位の決めごとを1つ上の階層に置いた
