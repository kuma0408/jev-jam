# 0039. 押せる和音を1オクターブ下（C3）まで広げる。低いところでは音を減らして濁らせない

- 日付: 2026-10-14
- ステータス: Accepted
- 種別: 設計判断

## 背景

ユーザーの指摘は「伴奏の低音が高すぎる。もっと低い音も弾けるようにしてほしい」。自分で押す和音のことだった（自動のベースではない）。
押せる範囲は真ん中のド（C4）から2オクターブ上のド（C6）までで、それより下は押せなかった。

## 決定

- 押せる範囲を1オクターブ下のド（C3）まで広げた
- 低い音域で音を密集させると濁るので、和音の重ね方を変えた（`voicingUnder`）
  - G3 より低い音を押したら、下に重ねる音を3つから2つに減らす
  - E3 より低い音は、上の音と3半音以上空ける（2半音以内に詰めない）

## 結果

確認はダミー（`?mock=1`）のみ。エラーなし。

- 面のいちばん下を押すと、C3 を上にした3音の和音（例: Cmaj7 なら E2・G2・C3）が鳴る
- いちばん低い和音の下に重ねた音（E2 付近）は、画面の描く範囲より下なので描かれない（薄い補助線なので、そのままにした）
