# 0030. Jevと2小節ずつ交代で弾く（掛け合い）。Jevには「どう応えるか」を選ばせる

- 日付: 2026-10-13
- ステータス: Accepted
- 種別: 設計判断

## 背景

0029 で、旋律はユーザーが弾く方向に変えた。そのままではJevのソロとユーザーの旋律が重なり、Jevの使いどころも曖昧になる。
Jevを「ずっとソロを取る主役」から「聴いて応える相方」に置き直す。

## 検討した選択肢

交代の形:

- 2小節ずつ固定で交代: 分かりやすく、Jevが応えたことがはっきり伝わる / 弾かなかった番は伴奏だけになる
- 弾き終わったらJevが入る: 会話に近い / 境目が曖昧で、重なったり間が空いたりしやすい
- 4小節ずつ: ジャズの定番 / テンポ80だと1回12秒で、弾けない人には長い
- 長さを選べるようにする: 柔軟 / 設定が増える。まず1つの形で確かめたい

ユーザーの演奏をJevにどう渡すか:

- 弾いた音をそのまま渡す: 正確 / Jevは数えるのが苦手で、音の並びを渡しても読めない
- 言葉に要約して渡す: 音数（まばら・ほどほど・細かい）と向き（上がる・下がる・同じあたり・波）/ 粗いが、Jevが得意な形

## 決定

2小節ずつ固定で交代する。先にJevが2小節弾いて場を作り、次にユーザーが弾く。

- ユーザーの番に弾かれた音を覚え、音数と向きを英語の文に要約してJevに渡す（数字は入れない）
- Jevには応え方を4つから選ばせる: 真似る / 返す / 畳みかける / 落ち着かせる
- 選ばれた応え方を、ルールで音に効かせる
  - 音数: 真似るなら相手と同じくらい、畳みかけるなら多く、落ち着かせるなら少なく
  - 向き: 真似るなら相手と同じ向きの動きへ、返すなら逆向きの動きへ寄せる
  - 出だし: ユーザーが最後に弾いた音の近くから弾き始める。応えの出だしは休まない
- Jevが返した4つの確率を、そのまま画面に出す
- Jevへの依頼は、ユーザーの番の最後の小節で、間に合ういちばん遅い拍に出す（80BPMなら3拍目の頭）。できるだけ多く聴いてから応えるため
- 掛け合いでは、4小節の形（どこで休むか）は聞かない。自分の番は2小節しかない
- 掛け合いは設定で外せる（外すと、これまでどおりJevがずっとソロを取る）

## 結果

確認はダミー（`?mock=1`）のみ。本物のJevでは未確認。

- 番は Jev 2小節 → あなた 2小節 の順に切り替わった
- 上がっていく細かいフレーズを弾くと、要約は「busy / rising」になり、Jevへの依頼に入った
- Jevへの依頼は9小節で6件。ユーザーの番の小節では呼ばないので、これまで（1小節に1件以上）より減った
- 作り直し（盛り上がりが変わったときの再依頼）は、掛け合いでは止めた。応えの2小節目で同じ依頼が2回出ていたため

残った課題:

- 依頼を出した後に弾いた音（80BPMで最後の2拍）は、応えに反映されない
- 要約は音数と向きだけ。リズムの形（裏で入る、伸ばす）は伝えていない
- 「真似る」は向きと音数を寄せるだけで、弾いた旋律そのものをなぞるわけではない
- 本物のJevが4つの応え方をどう選び分けるか（偏りがあるか）は未測定

## 勉強会メモ

- Jevの置き場所を「生成する側」から「聴いて判断する側」に変えた。判断特化モデルの持ち味に寄せた形
- Jevは数えるのが苦手なので、演奏を「言葉」に直して渡している
- 確率をそのまま見せると、「迷った末にこれを選んだ」が伝わる
