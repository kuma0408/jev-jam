# 0051. デクレッシェンドの幅を広げ、フレーズの終わりを弱め、速い曲ではソロを大きめにする

- 日付: 2026-10-16
- ステータス: Accepted（0050 の強弱の倍率を置き換える）
- 種別: 設計判断

## 背景

ユーザーから2つ言われた。

- 「デクレッシェンドがもっとつくといいよね。今、割と音量単調になっちゃってるかも」
- 「テンポが速い時はユーザー側の入力が間に合わなくなって、どうしてもしっとりした判定になっちゃうのか、音量が小さくなりがち。早い時は基本は音量を大きめみたいなベースがあるといい」

調べると、速い曲の問題は判定のしきい値が拍と小節に縛られていたことだった。

- 平均1拍以上押さえると「しっとり」。200BPMでは1拍0.3秒なので、少し押さえただけでしっとりになる
- 1小節に6回押すと「激しい」。200BPMでは1小節1.2秒なので、1秒に5回押す必要がある

しっとりと判定されると、Jevへの合図、ルールで決める音数、ソロの音量の倍率がそろって静かな側に寄る。

単調さは、0050 で強弱の動きの幅を上限に当たらないようにそろえたとき、デクレッシェンドが 1.0→0.6 と狭くなっていたことが大きい。

## 検討した選択肢

速い曲（ユーザーの選択）:

- 判定を秒でも測る＋テンポで音量の底を上げる（採用）
- 音量の底上げだけ: 判定は静かなままで、Jevへの合図や音数は変わらない
- 判定を秒で測るだけ: 何も弾かないときの音量は変わらない

音量の変化（ユーザーの選択。複数選択）:

- 強弱の動きの幅を広げる（採用）
- 休みの直前の音を弱めてフレーズを閉じる（採用）
- 高い音ほど少し大きく（見送り）
- 4小節の強弱の流れをJevに選ばせる（見送り。質問が増え、本物のJevでの確認も要る）

## 決定

- 押し方の判定
  - しっとりは「平均1拍以上」に加えて「0.6秒以上」も満たすこと
  - active / busy は、1小節の回数（3回 / 6回）と、1秒あたりの回数（1.5回 / 3回）の、届きやすいほうで決める。遅いテンポではこれまでどおり
- テンポによる音量の底上げ: 140BPMまでは1倍、220BPMで1.3倍。伴奏の質感の倍率と掛け合わせず、大きいほうを使う
- 強弱の動きの幅: いちばん弱いところを 0.6 → 0.35 にした（クレッシェンド 0.35→1.0、デクレッシェンド 1.0→0.35、山 0.55→1.0→0.55）
- フレーズを閉じる: 後ろに1拍以上の無音がある音を「フレーズの終わり」とし、そこから前の3音に後ろから 0.7、0.82、0.92 を掛ける。小節の終わりまで鳴っている音は、次の小節で続くかもしれないので弱めない
- 上の2つで平均の音量が下がったので、強さの基準を soft 0.40→0.45、medium 0.64→0.70、loud 0.90→0.95 に上げた

## 結果

テスト549件、型チェックが通った。ダミーの確率で32小節つないで、ソロの音の強さを測った（伴奏は弾いていない想定、同じ乱数の列）。

| テンポ | 平均の強さ（前→後） | ばらつき（標準偏差÷平均、前→後） |
| --- | --- | --- |
| 80BPM | 0.58 → 0.55 | 0.30 → 0.33 |
| 220BPM | 0.51 → 0.59 | 0.39 → 0.46 |

- 途中で、幅を広げただけでは平均が 0.50 まで下がり、速い曲の底上げも打ち消されていた。基準値を上げて戻した
- 押し方の判定の変化は、ブラウザで実際に押して確かめていない。聴いた評価はユーザーの確認待ち
- 本物のJevは呼んでいない

## 勉強会メモ

- 「速い曲で音が小さい」の原因は音量ではなく、ユーザーの操作の判定だった。拍で測るしきい値は、テンポが変わると意味が変わる
