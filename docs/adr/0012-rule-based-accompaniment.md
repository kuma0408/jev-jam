# 0012. 伴奏はルールで動かし、Jevは使わない

- 日付: 2026-10-13
- ステータス: Accepted
- 種別: 設計判断

## 背景

伴奏は、ベースとコードを小節いっぱい伸ばすだけだった。ユーザーから次の要望が出た。

- 伴奏もリズムを刻みたい（裏から入る、短く切る、休符を入れる）
- ドラムがほしい。固定のパターンでよく、4小節や8小節ごとに最後の小節でフィルを入れたい

## 決定

伴奏はルールだけで作る。Jevに選ばせる対象はソロに絞る。伴奏まで判断させると、
1小節あたりの質問が増えるわりに、体験の核（ソロ）への効果が薄いため。

- ベース: 4分音符で歩く。ルート、3rd、5thと上がり、4拍目は次のコードのルートへ半音で寄る
- コード: ルートを省いた3音を、5種類のリズムの型（チャールストン、裏拍の短い突き、長い伸ばしなど）から乱数で選ぶ
- シンバル: チン・チンチキを刻み、4小節ごとの最後の小節は刻みを足して区切りを付ける

ベースが寄っていく「次のコード」は、ユーザーが選ばなければ進む既定の候補とした。
ユーザーが小節の途中で別のコードを選ぶと、ベースの4拍目は外れた方向へ寄ることになる。許容した。

## 結果

実装し、テストで音域や拍の位置を固定した。聴いた評価はユーザーの確認待ち。

できていないこと。

- 本物のドラム（キック、スネア）は無い。シンバルはノイズから作った合成音である。
  ライセンスが明記された生ドラムの音源が見つかっていない（0009）
- フィルは刻みを足すだけの簡素なもの
- コードのリズムの型は乱数で選んでいて、ソロの盛り上がりには反応しない
