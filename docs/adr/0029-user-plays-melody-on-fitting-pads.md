# 0029. 旋律はユーザーが弾く。弾けない人のために「合う音だけの鍵盤」を用意する

- 日付: 2026-10-13
- ステータス: Accepted
- 種別: 設計判断

## 背景

0028 でコードも音も自由に弾けるようにしたが、触った感想は「まだ微妙」だった。
旋律はJevが進め、ユーザーはコードを選ぶだけなので、自分の操作と鳴る音の距離が遠い。

「旋律をユーザーが弾けたほうが楽しいのでは。でもそれだとJevの使いどころがなくなるのでは」という疑問が出た。
さらに「弾けない人は旋律を生み出せない」という問題もある。

## 検討した選択肢

Jevの役割:

- 掛け合い: ユーザーが2小節弾き、Jevが内容を読んで2小節で応える / Jevの判断（真似る・発展・対比）が一番見える。いまの「前との関係」の質問を流用できる
- リズムは人、音はJev: 叩くだけで高さはJevが決める / 外れないが、Jevの判断が見えにくく、自分で弾いた感覚も薄い
- Jevは伴奏側: 自由に旋律を弾き、Jevは伴奏とコードを判断 / 弾ける人向けで「誰でも」から離れる

弾けない人が旋律を作る方法:

- 合う音だけの鍵盤: 横一列の8キーを、いまのコードに合う音に割り当てる / どれを叩いても外れない
- 上げる・下げるの2〜3キーだけ: 一番簡単だが、音を選んだ感覚が薄く単調
- 真似から始める練習形式: 分かりやすいが、ゲームの練習に近く、アドリブの自由さから離れる

## 決定

掛け合い＋合う音だけの鍵盤にする。まず鍵盤、次に掛け合いの順で作る。

- 8つのキー（A S D F G H J K）に、いまのコードの上で伸ばしてよい音だけを低い順に並べる（`padPitches`）
- コードが変わると音が入れ替わるが、「左が低く右が高い」並びと、おおよその高さは変わらない
- ぶつかる音（Cmaj7 の F など）は飛ばす
- 0028 の「嘘はつかない」は守る。ピアノの鍵を別の音にすり替えるのではなく、最初から別の鍵盤として見せ、鳴る音名を鍵に書く
- 弾ける人のために、12音の鍵盤へ切り替えられるようにする

## 結果

鍵盤は実装した（掛け合いはこれから）。確認はダミー（`?mock=1`）のみ。

- 8キーすべてが鳴り、Cmaj7 では E G A B C D E G、G7 に変えると E F G A B D E F に入れ替わった
- 12音への切り替えも動き、エラーなし

残った課題:

- 弾いた音の内容は、まだJevに伝えていない（掛け合いで伝える）
- 押さえたままコードが変わったとき、鳴っている音はそのまま残る（新しいコードに合わなくなることがある）
- 8キーは約1オクターブ半。もっと高い音や低い音は弾けない

## 勉強会メモ

- 「判断するAI」の置き場所は、主役（ソロを弾く）より相方（聴いて応える）のほうが伝わるのでは、という転換点
- 制約（合う音しか無い）を付けると、かえって自由に弾ける
