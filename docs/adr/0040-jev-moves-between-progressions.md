# 0040. 8小節ごとの区切りで、Jevが定番進行を続けるか、別の進行へ移るかを選ぶ

- 日付: 2026-10-14
- ステータス: Accepted
- 種別: 設計判断

## 背景

ユーザーから「基本のコード進行は完全に固定？もうちょっと曲調が途中で変えられると面白い。でも音楽的に成立しづらくなるよね」と聞かれた。

実際は固定ではなく、毎小節、定番進行の一覧とこれまでの流れを照らし合わせて候補を出していた。ただ何も選ばないと、いちばん定番の候補へ自動で進むので、1つの定番進行に乗ると同じ4小節を延々と繰り返していた。

## 検討した選択肢

- 別の定番進行へ移る: 調は C のままなので安全。変化はリズムより控えめ
- リズムの雰囲気を変える（スウィング、ボサノバ、バラード）: 和音は同じで外れにくく、変化がいちばん分かりやすい
- 両方: 変化は大きいが、作る量も多い
- 転調する: 盛り上がるが、すべてのコードを C の調で持っている作りを大きく変える必要がある

区切りの長さは 8 / 16 / 4 小節を比べた。

## 決定

別の定番進行へ移る、を8小節ごとの区切りで行う（ユーザーの選択）。移るかどうかと、どこへ移るかはJevに選ばせる。

- 繰り返し型の定番進行9つに、ID と雰囲気の英語の説明（`mood`）を付けた。例: 王道進行「Bright but wistful and emotional」
- 移り先の候補は、区切りの次の小節で進めるコードから始まる進行だけにする（`sectionOptions`）。いまの流れから自然につながるので、どれを選んでも音楽として成り立つ。いまの進行は外す
- 区切りの1小節前のソロの依頼に、質問を1つ足す（「続ける」か、移り先のどれか）。Jevの呼び出し回数は増えない
  - いまの進行と、それを続けている長さを言葉で渡す（始まったばかり / しばらく / 長い間）。Jevは数えるのが苦手なので小節数は渡さない
- Jevの確率から抽選し、移るなら区切りの頭の小節を移り先の最初のコードにする
- 移った後は、その進行の続きを候補の先頭に寄せる（`nextChordCandidates` の `prefer`）。ユーザーが別のコードを弾いて外れたら、自然に寄せなくなる
- 進行が変わった小節には、五線の上に小さく「→ 進行名」を出す。「裏側を見る」の記録には、Jevが返した確率の上位3つを出す
- 掛け合いの間は聞かない

## 結果

ダミー（`?mock=1`、確率はでたらめ）で、テンポ200で26小節流した。

- 9小節目: このまま（カノン進行）
- 17小節目: → I-IVの往復
- 25小節目: → 循環（I-VI7-II-V）
- エラーなし。区切りの前の依頼にだけ質問が付いた

残った課題:

- 本物のJevが、雰囲気の説明と続けている長さをどう判断に使うかは未測定
- 「I-IVの往復」のような2コードの進行に移ると、8小節が単調になりやすい
- 8小節の進行（カノン進行）は、区切りと頭がずれた位置から始まることがある
