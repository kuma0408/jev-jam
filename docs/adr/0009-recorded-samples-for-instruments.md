# 0009. 楽器の音は合成音をやめ、公開されている録音音源を使う

- 日付: 2026-10-13
- ステータス: Accepted
- 種別: 技術選定

## 背景

ソロの音を合成音（シンセ）でテナーサックス風に調整したが（0007）、聴いた評価は「かなりダサい」だった。
合成音ではリード楽器らしさに限界があり、ユーザーから生音を使いたいという要望が出た。

## 検討した選択肢

- 案A: 合成音のまま調整を続ける。外部ファイルが要らないが、評価が改善する見込みが薄い
- 案B: 公開されている録音音源を取得し、Tone.jsのサンプラーで鳴らす。本物に近づくが、ライセンスの確認とファイルの管理が要る
- 案C: 実行時に配布元のサーバーから読み込む。リポジトリは軽いが、配布元が止まると音が出ず、限定公開時に外部依存が残る

## 決定

案B。音源は `public/samples/` に置き、出典とライセンスを同じ場所の README に記す。

| 用途 | 音源 | ライセンス |
| --- | --- | --- |
| ソロ（3種を画面で切り替え） | tonejs-instruments の saxophone（楽器の録音） | CC BY 3.0 |
| | FluidR3_GM の tenor_sax | CC BY 3.0 |
| | FluidR3_GM の electric_piano_1 | CC BY 3.0 |
| 伴奏 | FluidR3_GM の electric_piano_1 | CC BY 3.0 |
| ベース | FluidR3_GM の acoustic_bass | CC BY 3.0 |

ソロの音源を1つに決めず3種を入れたのは、音色は聴かないと判断できないため。再生中に切り替えて比べられる。

容量を抑えるため、短3度おきの音だけを取得した（42ファイル、約2.3MB）。間の音はサンプラーが近い音から作る。

## 結果

- 音源ごとの音量差が大きかった。ブラウザ上でデコードして最初の1秒の音量を測ると、
  録音のサックスは約-10dB、FluidR3_GMの各音源は約-28〜-30dBで、18dBほど差があった。音源ごとに補正値を持たせてそろえた
- 録音のサックスは、各ファイルの頭に約28msの無音がある。発音がそのぶん遅れるが、今は補正していない
- 録音のサックスは種類（アルトかテナーか）が配布元に書かれていない。収録音域は C#3〜A5
- ドラムは見送った。Tone.js公式の音源置き場に生ドラムの単発音があるが、ライセンスの記載が見つからなかった。
  拍の音は合成のハイハットのまま。ドラムパターンを作る段階で、ライセンスが明確な音源を探す
- 聴いて良くなったかは、ユーザーの確認待ち

## 勉強会メモ

- 「使える音源」は多いが「ライセンスが明記された音源」は少ない。ドラムはそこで止まった
- 自分では音を聴けないので、音量は波形を数値で測ってそろえた。聴けない制約下での工夫として話せる
