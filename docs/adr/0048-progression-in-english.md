# 0048. いまの進行は、日本語の名前ではなく英語の雰囲気の説明でJevに伝える

- 日付: 2026-10-16
- ステータス: Accepted
- 種別: 設計判断

## 背景

発表資料を作る中で、ユーザーから「サンプルで丸サ進行って日本語で書いてあるけど、Jevはそれを解釈できるの？」と聞かれた。

8小節の区切りの前に `state` に入れる `current_progression` は、`丸サ進行. It has been going for a while.` のように、画面に出す日本語の名前をそのまま使っていた。Jevに渡すほかの文はすべて英語で書いていて、ここだけが日本語だった。

公式の記載（Qiitaの解説記事経由で確認）では、Jevは主に英語で訓練されていて、日本語も読めるが精度は落ちる。「丸サ進行」のような日本の音楽用語を知っている保証も無い。日本語で渡したときにJevがどう読んでいるかは測っていない。

## 検討した選択肢

- 案A: 進行ごとの英語の雰囲気の説明（`mood`）に置き換える。移り先の選択肢の説明文ですでに使っている文なので、いまの進行と移り先が同じ言葉で並ぶ
- 案B: 英語の名前（Marusa progression など）に置き換える。日本語よりは読めるが、Jevがこの呼び名を知っている保証は無い
- 案C: 直さない

## 決定

案A（ユーザーの選択）。`current_progression` は `{雰囲気の説明} {続けた長さ}` にする。雰囲気の説明が無い進行は、名前を出さずに `A free-flowing progression.` とする。

## 結果

- テスト2件を足し（日本語の名前を含まない、説明が無いときは決まった英語）、530件すべて通った
- 本物のJevでの判断の変化は測っていない

## 勉強会メモ

- 「Jevに渡す文は全部英語」のつもりでも、画面用の名前がそのまま混ざっていた。資料を作って人に説明する段階で見つかった
