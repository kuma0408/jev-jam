# 0044. 文字をほぼ無くし、押すたびに弾けるエフェクトと、曲調で移ろう色にする

- 日付: 2026-10-14
- ステータス: Accepted
- 種別: 設計判断

## 背景

ユーザーの要望。

- 文字が多くて野暮ったい。文字での説明は最低限、なんならなくてもいい。直感的に操作できると分かるUIにしたい
- エフェクトをもっと洗練されたかっこいいものにしたい。patatap（https://patatap.com/）のエッセンスを取り入れて、音を弾くたびに気持ちいいエフェクトが出るように
- 背景のカラフルな点のテイストを変えたい。流れる砂、図形のカットイン、点の集合と拡散など、レパートリーを持たせたい
- 曲調に合わせて色味がどんどん変わっていく体験にしたい（「帳」と書かれていたので、曲調・コード・調のどれかを聞いて、「曲調（進行）＋コード」と確認した）
- 隠している「裏側を見る」は今のままでいい

## 検討した選択肢

色の変化のきっかけ:

- 曲調（進行）＋コード: 進行が移ると大きく、コードごとに少しずつ変わる。変化にメリハリが出る
- 曲調（進行）ごと: 分かりやすいが、移らない間は変わらない
- コードごと: いつも動くが、曲調が変わった大きな節目が伝わりにくい

地の色:

- 白基調に色をにじませる: 上品で、帯や線も読みやすいまま
- 地の色ごと大胆に変える（patatap 風）: 印象は強いが、帯や線との見分けを色ごとに調整する必要がある
- 暗い地: 光と相性は良いが、これまでの白基調から大きく変わる

## 決定

曲調（進行）＋コード、白基調に色をにじませる（ユーザーの選択）。

### 色（`lib/visual/palette.ts`）

- 繰り返し型の進行ごとに、基準の色相と背景の表情を決めた（丸サ進行は夜の街の青、Just the Two of Us は夕暮れの橙、ツーファイブワン循環は真鍮の黄など）。見分けられるよう、色相どうしを20度以上離した
- 基準の色相から5色を作る: 地のにじみ（明るさ96%）、あなたの和音、Jevの旋律（あなたの色から150度回す）、深い色、光
- コードが変わるたびに、5度圏の位置で色相を±20度ずらす。隣り合うコードほど近い色になり、進行に沿ってなめらかに移ろう
- 深い色と地は、明暗差（コントラスト比）7以上をテストで保証した
- 色は一定時間かけて移ろわせる（コードで1.6秒、進行が移るときは0.9秒）。地の色は CSS 変数、canvas は描くたびに同じ置き場所（`theme-store.ts`）から読む

### 押したときのエフェクト（`visual/flourishes.ts`、`flourish-layer.tsx`）

- 画面全体に透明な canvas を重ね、クリックは下へ通す
- 5種類を、5回で全種類を1回ずつ、周ごとに並び順を変えて出す（`pickFlourish`）: 輪が広がる / 大きな図形（三角・半円・長方形）が画面の端から差し込んで抜ける / 平行線が押した高さで横切る / 紙吹雪が弾ける / 多角形が回りながら広がる
- 高いところを押すほど大きい（`flourishScale`）
- 長く押さえて離すと、押した位置から地がその色に染まって引く
- 進行が移るときは、新しい色の幕が画面を斜めに横切る
- Jevの音には、小さな光のまたたきを、3割ほどの音にだけ出す（全部に出すとうるさい）

### 背景（`backdrop.tsx`。それまでの particle-field.tsx を置き換えた）

- 進行ごとに3つの表情のどれか: 流れる砂（細かい粒がうねる流れに乗る） / 集まって散る粒（拍で集まり、小節の頭で散る） / 図形の断片（細い線と三角が漂い、拍で脈打つ）
- 表情が変わるときは、前の表情を1.4秒かけて消しながら出す
- 盛り上がりで動きの速さを変える

### 文字を減らす

- 演奏面の下の説明文と凡例を消した（説明は読み上げ用にだけ残した）
- 開始の合図を、脈打つ円と再生の三角にした。準備中は円が回る
- 停止を、■の形だけの丸いボタンにした（読み上げ用の名前は「停止」）
- 速いテンポや1小節に2つのコードのときにコード名が重なっていたので、次のコード名とぶつからない大きさに縮め、半分まで縮めても入らなければ書かないようにした。進行名はコード名の下に置いた

### 動きを減らす設定

- 背景は動かさず、通知が来たときだけ描く
- エフェクトは、動かずにその場で薄い円が消えるだけ（進行が移るときは画面全体が薄く色づくだけ）
- 開始の合図は脈打たない

## 苦労したこと

- 集まって散る粒が、画面に1つも見えなかった。小節の頭で弾き飛ばした後、持ち場へ引き戻す力が弱すぎて、画面の外へ散ったままだった。引き戻しと減速を強めた
- エフェクトの出し分けで、最初は乱数を渡す形でテストを書いた。押すたびに独立に乱数を引くと、1周の中で同じものが出る。押した回数だけで決まる形にテストを直してから実装した
