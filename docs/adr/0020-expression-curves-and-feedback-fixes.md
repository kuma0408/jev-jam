# 0020. 一音の中の音程と音量を曲線で動かし、聴いた指摘を直す

- 日付: 2026-10-13
- ステータス: Accepted（0017を広げる）
- 種別: 工夫

## 背景

0017のしゃくりを聴いた評価は「結構いい感じ」だった。そのうえで次の指摘が出た。

- しゃくりは全音下げなくてよい。半音からにしてほしい
- 一音の間で音量に変化を付けたい。特にテンポが遅いとき、伸ばした音が単調に聞こえる
- しゃくり以外の変化も入れてほしい
- A・S・D・Fキーが効かないことがある
- 自分で弾く音が小さく、演奏している感が少ない
- 16分音符のフレーズをもう少し選ばれやすくしたい。バラードの中でもときどき入るとかっこいい。スウィングは不要

## 決定

### 吹き方を5種類に

| 表現 | 付ける場面 | 中身 |
| --- | --- | --- |
| しゃくり | フレーズの入り、休符の後、跳び上がった先（6割） | 半音下から最長0.14秒で届く |
| 音量の動き | 0.5秒以上の音 | ふくらむ35%、しぼむ30%、ふくらんで戻る25%、変化なし10% |
| ビブラート | 0.6秒以上の音 | 音の4割を過ぎてから、±0.22半音で揺らす |
| フォール | フレーズの最後の0.35秒以上の音（35%） | 終わりの3割で3半音落とし、音量も絞る |
| なめらかなつなぎ | 2半音以内へ切れ目なく進む音 | 立ち上がりを0.035秒にしてやわらかくする |

### 曲線として予約する

1音の吹き方を、10ミリ秒刻みの「音程のずれ」と「音量の倍率」の2本の曲線に直してから、音源に渡す。
しゃくり、ビブラート、フォールを別々の予約として重ねると、時刻が重なったときの扱いが難しい。
1本の曲線にまとめれば重なりが起きず、曲線そのものを数値としてテストできる。

### 16分音符

- 16分音符を含むリズムはすべてスウィングさせない（1つだけ残っていたスウィングの型も均等にした）
- 遅いテンポでは2.5倍、中間では1.5倍、選ばれやすくする
- バラードに差し込みやすい、音数の少ない16分音符のリズムを2つ足した
  （1拍待って4つ入る、長く伸ばしてから3つで次へつなぐ）

### 自分で弾く音

自動の伴奏と同じ音源・同じ音量で鳴らしていたので、埋もれていた。専用の音源に分け、8dB大きくした。
刻むコードはいちばん上の音を1オクターブ上にも重ね、単音は1オクターブ上の音域にした。

## 結果

### キーが効かなかった原因

2つあった。

- キーの判定に「打たれた文字」（`event.key`）を使っていた。日本語入力がオンだと文字は確定前なので `"Process"` になり、
  どのキーか分からない。「物理的なキーの位置」（`event.code`）で判定するように直した。数字キーも同じ
- スライダーやつまみを触った後は、そこにフォーカスが残る。入力欄にフォーカスがあるとキーを無視する作りだったので、
  テンポを動かした後は弾けなくなっていた。無視するのは選択肢の一覧（select）だけにした

日本語入力オンを模したイベントを、スライダーにフォーカスした状態で送り、音が出ることを確かめた。

### 同じリズムが8小節続いた

16分音符を優遇した直後の確認で、足したリズム（long-sixteenth-pickup）が4〜11小節目のほぼ毎小節で選ばれた。
0019の「リズムを引き継ぐ」「繰り返す」が交互に選ばれると、同じリズムがいつまでも残る。
直前と同じ関係は選ばれにくくしていたが、関係の種類が違えば効かなかった。

2点を直した。

- 直近2小節の両方で使われたリズムや音の形は、もう引き継がせない
- 確率を下げる対象を「直前の1小節」から「直近4小節」に広げ、使った回数が多いほど大きく下げる

直した後、72BPM・盛り上がり「ゆったり」で20小節走らせた（1回）。

- 同じ前半リズムの連続は最長2小節
- リズムは16種類。16分音符を含む小節は20小節中11小節
- 遅延は中央550ms、最大680ms

### 分からないこと

- 音が良くなったかは、ユーザーの確認待ち。私は音を聴けない
- 16分音符が20小節中11小節は、「ときどき」より多いかもしれない。倍率（2.5）で調整できる
- 自分で弾く音の大きさ（+8dB）は当て推量

## 勉強会メモ

- 「機能を足した直後に、記録を見て副作用に気づいた」例。16分音符の優遇と、前に入れた引き継ぎの仕組みが掛け合わさって、
  どちらも単独では起きない偏りが出た。聴けない代わりに、選ばれたものの記録を毎回読んでいる
- `event.key` と `event.code` の違いは、日本語環境で必ず踏む。英語配列だけで試していると気づかない
