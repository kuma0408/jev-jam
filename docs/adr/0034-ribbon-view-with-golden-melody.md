# 0034. 表示は「光の帯と線」に決める。Jevの旋律は金色の光の線にする

- 日付: 2026-10-14
- ステータス: Accepted
- 種別: 設計判断

## 背景

0033 で3種類の表示（光の帯と線、幾何学模様、波紋と粒）を作り、見比べてもらった。
ユーザーの評価は「光の帯と線の路線は結構いい。特に伴奏の感じはかなりいい。ただ主旋律の表現がちょっとダサい。黒い丸と黒い線は工夫できるかな。色を変えるとか、エフェクトを付けるとか」。

## 決定

光の帯と線に決め、ほかの2つと「表示（お試し）」の切り替えは消した。Jevの旋律の描き方を変えた。

- 色は、伴奏の青と対になる金色（真鍮の管楽器の色）にした
- 線は2回描く。太くぼかした橙の光と、細い金の芯。左（過去）へ行くほど薄くする
- 音の鳴り始めに、光の輪が広がって消える（0.6秒）。強い音ほど大きく広がる
- 鳴り始めの点は、白に近い金の芯を持つ光の点にする
- いま鳴っている音の先端を、彗星の頭のように光らせる
- 前回の階段のような線（音の長さぶん水平に伸ばしてから縦につなぐ）はぎこちなかったので、鳴り始めの点を Catmull-Rom 曲線でなめらかにつなぐ形にした

## 結果

確認はダミー（`?mock=1`）のみ。エラーなし。見た目の評価はユーザー待ち。

- 動きを減らす設定のときは、ぼかしと光の輪を止める
