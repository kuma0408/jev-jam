# 0018. ユーザーが自分でも音を出せるようにし、その叩き方にバンドが応える

- 日付: 2026-10-13
- ステータス: Accepted
- 種別: 設計判断

## 背景

ユーザーから「伴奏側が音楽に参加している感をもっと増やしたい」という要望が出た。
コードを選ぶだけでなく、そのコードの音を弾けるようにしたい。ただし、次のコードを選ぶのが遅れるのは困る、という懸念も示された。

## 決定

コードを選ぶ操作と、音を出す操作を、別のキーに分けた。提案した3つをすべてユーザーが採用した。

- コードを刻む: スペースキー（または画面のボタン）で、いまのコードが押した瞬間に鳴る。音程は考えなくてよい
- コードの音を弾く: A・S・D・Fキーに、いまのコードの構成音4つを割り当てる。小節ごとに入れ替わるので、何を押しても外れない
- 叩き方にバンドが応える: 直近1小節に叩いた回数を、盛り上がりに足す。3回以上で1段階、6回以上で2段階上がる

叩き方は2通りでソロに伝える。盛り上がりの値として（0015の4か所に効く）、
そして `state` の `accompanist` に「人間のピアニストが激しく刻んでいる。応えよ」という文として。

ユーザーがコードを刻んだ次の小節は、自動のコード伴奏を黙らせる。刻むのをやめれば自動の伴奏が戻る。

## 結果

再生しながら試した（120BPM）。

- スペースを4回叩くと盛り上がりが1段階上がり、続けて4音弾くと2段階上がった
- 上がった盛り上がりは、次の小節のソロに反映された（記録の「盛り上がり」が、ゆったり → 激しい）
- 叩くのをやめると、3小節ほどでつまみの位置に戻った

「参加している感」が出たかは、ユーザーの確認待ち。

できていないこと。

- 押した音は拍に合わせていない。押した瞬間にそのまま鳴る
- 音の強さは一定。キーボードでは叩く強さが取れない
- ユーザーが弾いた音の高さやリズムは、Jevに伝えていない。伝えているのは回数だけ

## 勉強会メモ

AIと人の「往復」を作る最小の形として、人の入力を1つの数（叩いた回数）に畳んでJevの判断材料にした。
入力を細かく伝えるほど良いとは限らず、まずは効きが分かりやすい1本の線でつないだ。
