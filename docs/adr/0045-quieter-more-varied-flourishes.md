# 0045. エフェクトを控えめにし、種類を5から12に増やす

- 日付: 2026-10-14
- ステータス: Accepted
- 種別: 設計判断

## 背景

0044 のエフェクトを見たユーザーの評価は「ちょっとやかましい。もうちょっと抑えめで、ただバリエーションはもうちょっと増やしてほしい」「透過度を上げて、あんまり目立ちすぎないように。ちょっとド派手すぎる」。

## 決定

### 抑える

- エフェクトの層ごと透明度を上げた（不透明 → 60%）
- 大きさの倍率を 0.6〜1.4 から 0.45〜0.95 にした
- 画面の端から差し込む図形を、画面の約3割から約1.6割の大きさに縮め、濃さを 0.85 から 0.45 にした（演奏面を覆っていたため）
- 輪の太さと広がり、平行線の太さ、紙吹雪の数（22 → 12）と飛ぶ距離、多角形の広がりを下げた
- 長く押さえて離したときに地を染める濃さ（0.22 → 0.1）と、進行が移るときの幕の濃さを半分にした

### 増やす

静かめのものを7つ足して12種類にした。

- やわらかな光がふわっと広がる（bloom）
- 細い斜めの線がすっと抜ける（streak）
- 小さな点が弧を描いて扇状に広がる（fan）
- 6枚の楕円が花びらのように開く（petals）
- 四角の輪郭が回りながら広がる（square）
- 小さな縦棒がイコライザーのように伸び縮みする（bars）
- 小さな点が周りを回って消える（orbit）

派手なもの（もとの5種類）と静かなもの（新しい7種類）を交互に並べ、続けて押しても騒がしくなりすぎないようにした。12回で全種類を1回ずつ出し、周ごとに並び順を変え、周の変わり目でも同じものが続かないことをテストで確かめた。

## 結果

確認はダミー（`?mock=1`）のみ。12種類を順に出してエラーなし。演奏面の帯と線を覆わない程度になった。見た目の評価はユーザー待ち。
