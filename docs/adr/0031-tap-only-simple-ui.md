# 0031. 操作は「叩く」だけにする。叩く高さで盛り上がりを決め、ほかは「裏側を見る」に隠す

- 日付: 2026-10-14
- ステータス: Superseded by 0032（盛り上がりの決め方）
- 種別: 設計判断

## 背景

0029・0030 で、旋律をユーザーが弾き、Jevと2小節ずつ交代する掛け合いを作った。
触った感想は「ユーザー側が旋律を弾くのができなすぎて微妙」だった。

あわせて、コードの鍵盤、つまみ、旋律の鍵盤、設定と、ボタンや操作が増えすぎていた。
ユーザーの方針は「子どもでも、音楽を全然やったことがない人でも、シンプルにセッションの楽しさを味わえるアプリにしたい。ボタンやユーザー操作は増やしたくない」。

## 検討した選択肢

ユーザーの操作:

- 叩くだけ: いちばん迷わない / 表現の幅が狭い
- 叩く＋叩く場所でコードを変える: 曲を動かす感覚は増える / 何を選べばいいか迷う余地が出る
- 叩く＋叩く高さで盛り上がり: 表現の幅が増える / 説明しないと気づきにくい
- コードを選ぶだけ（これまでの延長）: 音楽的な判断が要り、未経験者には何を押せばいいか分からない

いまある鍵盤・つまみ・設定・記録:

- 「裏側を見る」に隠す: 普段は叩く面だけ。勉強会では開いて仕組みを見せられる
- 消す: いちばん簡単だが、Jevが何を選んだかを見せる手段がなくなる
- 別ページに分ける: 遊ぶ画面と同時に見られない

## 決定

叩く＋叩く高さで盛り上がり、を選んだ（ユーザーの選択）。既存の部品は「裏側を見る」に隠す。

- 画面の大部分を叩く面にする。どこを叩いても、いまのコードがそのリズムで鳴る
- 叩く面を上から「激しい・のってきた・ゆったり・静か」の4段に分け、文字で書く（色だけに頼らない）。いまの段には「いま」の印を付ける
- 直近1小節に叩いた高さの平均で、盛り上がりを決める（`energyFromTaps`）。上ほど音も強く鳴らす
- 叩くのをやめると「ゆったり」に戻る。「静か」に戻すと、黙っているときにソロが寂しくなりすぎるため
- 最初の1回の叩きで始まる（開始ボタンをなくした）
- キーボードでも遊べる: スペースで叩き、上下キーで叩く高さを4段で動かす
- コード進行は自動。コードの鍵盤は裏側に残すので、数字キーで弾くこともできる
- 盛り上がりのつまみは消した。叩く高さと役割がぶつかるため
- 掛け合いは既定でオフにした（裏側の設定で入れられる）

## 結果

確認はダミー（`?mock=1`）のみ。

- 上の方を連打すると「激しい」になり、Jevへの依頼も盛り上がり4になった
- 叩くのをやめて2小節待つと「ゆったり」に戻った
- 下の方を叩くと「静か」になった
- キーボードで上キー2回からスペースを叩くと「のってきた」になった
- エラーなし

残った課題:

- 盛り上がりが変わっても、ソロに効くのは次の小節から。叩いた瞬間に変わるのは自分の鳴らすコードの強さだけ
- 叩いたリズムそのものは、まだJevに伝えていない（次の候補）
- 叩く面の段は4つあるが、音の違いが4段階はっきり聞き分けられるかは未確認

## 勉強会メモ

- 機能を足すより削るほうが、体験が良くなった例
- 「旋律を弾かせる」は自分たちには楽しくても、未経験者にはハードルだった
