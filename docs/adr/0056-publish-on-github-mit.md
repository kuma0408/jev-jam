# 0056. GitHubに公開する。コードはMIT、音源はCC BY 3.0のまま分けて表示する

- 日付: 2026-10-16
- ステータス: Accepted
- 種別: 設計判断

## 背景

リポジトリを `kuma0408/jev-jam` として一般公開することにした。公開前に、履歴を含めて出してはいけないものがないかを確認し、READMEとライセンスを整える必要があった。

## 検討した選択肢

- コードのライセンス
  - 案A: MIT / 短く、誰でも気軽に試せる
  - 案B: Apache-2.0 / 特許条項がある。デモには重い
  - 案C: ライセンスなし / 公開しても他人が使えない
- READMEの既定の言語
  - 案A: 英語を `README.md`、日本語を `README.ja.md` / 対外的に一般的
  - 案B: 日本語を既定にする / 主な読者が日本の人ならこちら

## 決定

- コードはMIT。`public/samples/` の音源は CC BY 3.0 なので、MITの対象外であることとクレジットを、`LICENSE` とREADMEの両方に書いた。音の一部だけを抜き出したことも明記した（CC BYは改変の表示も条件のため）
- READMEは英語を既定にし、日本語版と相互にリンクで切り替えられるようにした
- 全160コミットの作者メールアドレスを、個人のgmailからGitHubのnoreplyアドレスに書き換えた。まだ一度もプッシュしていなかったので、誰にも影響しない
- `AGENTS.md` の「社内SWE勉強会」は「SWE勉強会」にした

## 結果

- 全履歴を検索し、APIキー、トークン、Basic認証の値、社名、人名は見つからなかった。`.env` は一度もコミットされていない。長いランダム文字列はすべて `pnpm-lock.yaml` のハッシュだった
- 日本語版READMEは natural-japanese スキルの lint で検出0件にした
- 画面の文言は日本語のままなので、英語版READMEにはその旨を書いた

## 勉強会メモ

- 公開前の確認は「今のファイル」だけでなく「履歴」も見る。作者のメールアドレスも履歴の一部
